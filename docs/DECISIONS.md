# Decision log

Lightweight ADR-style log. Append new entries at the **top**. Status: **Accepted** unless noted.

---

## 2026-10-06 — Product docs and agent autowiring

**Context:** Requirements and UX rules lived in chat history; agents needed repeatable context without re-reading the full thread.

**Decision:** Add `PRODUCT.md`, `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`, and `AGENTS.md`. Ship Cursor autowiring: project skill `.cursor/skills/cagescale/SKILL.md`, always-on rule `.cursor/rules/cagescale.mdc`, and data-scoped rule `.cursor/rules/cagescale-data.mdc`.

**Consequences:** Agents should read PRODUCT + ARCHITECTURE + DECISIONS before substantive edits; non-trivial choices get new DECISIONS entries.

---

## 2026-10-06 — No “current champion” labels in UI

**Context:** Seed data includes `isCurrent` / interim flags for ordering and research, but titles change frequently.

**Decision:** Remove Champ/Interim badges and one-liner suffixes. Show historical facts only (name, first belt year, height).

**Consequences:** Less misleading UI; `isCurrent` may remain in data for future features or Vacant logic.

---

## 2026-10-06 — Optional local fighter photos

**Context:** Placeholder initials are fine for demo; user will add real images over time.

**Decision:** `public/fighters_images/{fighter-id}.{webp|jpg|jpeg|png}` with `FighterPhoto` fallback chain.

**Consequences:** Zero code change per new image; filenames must match fighter slug ids.

---

## 2026-10-06 — Listed heights as separate map

**Context:** 50+ fighters; heights are stable metadata.

**Decision:** `fighter-heights.ts` keyed by id; merged in `FIGHTERS` export. Display `cm / ft'in"` everywhere.

**Consequences:** Adding a fighter requires a height entry (throws if missing).

---

## 2026-10-05 — Header gender + unit controls

**Context:** Men/Women was per-section; kg/lb was only on My Weight page.

**Decision:** Shared header switches (top-right): gender row + unit row; `DualWeight*` components honor unit order/bold.

**Consequences:** Fighter profile routes hide header switches; unit preference persists in memory for session.

---

## 2026-10-05 — Divisions accordion + expanded highlight

**Context:** Long page of champion carousels is heavy on mobile.

**Decision:** Default collapsed one-liner; expand shows cards; only one division open; expanded block uses darker muted background.

**Consequences:** Parent page owns `expandedId` state; gender change resets expansion.

---

## 2026-10-05 — My Weight 3-column layouts

**Context:** Stacked “above / you / below” and estimate cards used too much vertical space.

**Decision:** CSS grid `grid-cols-3` for class neighbourhood and estimates (Bulk / Cut / Dehydrate).

**Consequences:** Copy shortened in estimate columns for narrow widths.

---

## 2026-10-05 — Vercel SPA hosting

**Context:** TanStack Router client-side routes need fallback to `index.html`.

**Decision:** `vercel.json` with Vite framework preset + catch-all rewrite. No Nitro/SSR.

**Consequences:** Simple deploy; no server functions in repo.

---

## 2026-10-05 — Curated static data (no live API)

**Context:** User chose option A; UFC title history is researchable but APIs are brittle/paid.

**Decision:** Static seed in repo; TanStack Query for shape compatibility only.

**Consequences:** Manual updates for champions; research cited in README.

---

## 2026-10-05 — Stack: Vite + TanStack Router/Query + shadcn-style

**Context:** User requested bulletproof React organisation, not Next.js.

**Decision:** File-based routes in `src/pages/`; feature-sliced folders; minimal shadcn primitives in `shared/ui`.

**Consequences:** `routeTree.gen.ts` committed/generated by plugin; alias `@/` → `src/`.

---

## 2026-10-05 — Product scope: last 5 champions

**Context:** “Last X champions” — agreed on **5** per division for seed density vs mobile width.

**Decision:** `RECENT_CHAMPIONS_COUNT = 5` in `entities/weight-class/model/constants.ts`.

**Consequences:** Lineages in `champions.ts` maintain at least 5 entries per active division where history exists.
